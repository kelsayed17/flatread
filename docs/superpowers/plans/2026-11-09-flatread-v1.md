# flatread v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace flatread 0.4 with layout classes. Each class declares one table, and its `frame` and `rows` readers are derived from that declaration. Every format reads on one native polars or fastexcel path, shared by about 20 prism-clients packages.

**Architecture:** Each format base (`Csv`, `Sheet`, `Json`, `FixedWidth`) is a front-end that turns a body into a `Text` table: cells under the provider's labels, plus a way to locate a row for an error. One shared core then types that table: labels, errata, missing tokens, typing, long, checks, filter and carry. A layout's settings are class attributes, validated and compiled once in `__init_subclass__`.

**Tech Stack:** Python 3.14, polars ≥ 2.0 (developed on 2.1), msgspec ≥ 0.22, fastexcel ≥ 0.21 (extra `excel`). Tooling: uv, pytest, syrupy, ruff `ALL`, ty (strict), deptry, import-linter, typos.

**Spec:** `docs/superpowers/specs/2026-11-09-flatread-v1-design.md` (approved 2026-11-09). Read it first: this plan names the files, signatures and tests, and the spec says what each setting means.

## Global Constraints

- The repository is public. Nothing about any downstream consumer's queries goes in it, and no recorded cassettes are copied into it.
- Use official format specs only. Settings exist only if they are in the spec's lists. A one-provider quirk is a hook, never a setting.
- v1 deletes the 0.4 API outright: no shims, no deprecated aliases.
- Version `1.0.0`. Dependencies: `msgspec>=0.22` and `polars>=2.0`. The `excel` extra is `fastexcel>=0.21` and `polars[calamine]>=2.0`. Drop `stream-unzip`, `pdfminer-six` and the `pdf` extra.
- Every error is a `flatread.errors.ReadError`, which is a `ValueError`, and names the location (line, sheet row or record), the label and the text.
- The success path builds no error message and tracks no line numbers.
- The CI gates stay as `.github/workflows/ci.yml` runs them, including coverage `--cov-fail-under=97`. Update the core-install smoke step (lines 79–85) to import `flatread` and `flatread.sheets`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. No push to main and no tag without the user's OK.

## Review Focus

1. **A BOM plus CRLF body on the CSV fast path** (ECB, IBKR). The BOM is dropped, no `\r` lands in the last field, and the sentinel check still passes. Test: `test_crlf_with_bom_reads_on_the_fast_path` (Task 4).
2. **A label written twice** (Nasdaq and NYSE `Filler`). The pairs form of `labels` maps each occurrence in order, and a mapping that can't express the repeat raises when the class is built. Test: `test_a_repeated_label_maps_by_order` (Task 3).
3. **An empty or whitespace-only body.** It raises `EmptyBodyError`, unless `min_rows = 0`, in which case the result is an empty frame with the row schema (ECB's zero-byte window). Test: `test_an_empty_body_with_min_rows_zero_is_an_empty_frame` (Task 3).
4. **A float too large for a double (`1e400`).** It reads as an infinity, so it is refused unless `nonfinite` is set. Test: `test_an_overflowing_float_is_refused` (Task 2).
5. **A quoted field holding a line ending.** The body takes the fallback, the record reads whole, and an error in a later row names the right line. Test: `test_a_multiline_quoted_record_reads_on_the_fallback` (Task 4).

## File structure

```
src/flatread/
  __init__.py      public names: Csv, Pipe, Tsv, Sheet, Json, FixedWidth, Long, Sheets, Line, Erratum,
                   QUARTER, YEAR_MONTH, EXCEL_SERIAL, report, diff, unzip (errors stay in flatread.errors)
  errors.py        ReadError tree
  cells.py         field type -> polars expression; one typing pass returning typed columns and bad masks
  core.py          Text dataclass; the shared pipeline from Text to the typed frame
  layout.py        Layout base: settings, __init_subclass__ checks, Plan, frame/rows/from_text, hooks, member, refusals
  archives.py      unzip(body) -> dict[str, bytes]; member selection
  delimited.py     Csv, Pipe, Tsv: sentinel fast path, csv fallback, Line (preamble/trailer)
  sheets.py        Sheet, Sheets (excel extra)
  records.py       Json (msgspec native decode, text mode, page)
  fixed.py         FixedWidth
  check.py         report() and diff()
  scaffold.py      sample -> row struct + layout source text
  __main__.py      `python -m flatread scaffold ...`
benchmarks/bench.py  v1 against the hand-written readers on prism-clients cassettes
tests/test_<module>.py per module; tests/fixtures/workbooks kept
```

### Task 2: Cell typing (`cells.py`)

### Task 3: The core and the `Layout` base (`core.py`, `layout.py`)

**Interfaces:**
- Consumes `fields_of`, `type_frame`, `first_bad` and `dtype_of` (Task 2).
- Produces, in `flatread/core.py`:
  - `Text`, a dataclass of `frame: pl.DataFrame` (text or native columns, named by label as written, with a repeat named `label#2`, `label#3`, …), `locate: Callable[[int], str]` and `carried: dict[str, str]` (field → text).
  - `Long`, a frozen dataclass of `index: tuple[str, ...]` (labels), `name: str` (field), `value: str` (field) and `names: str` (regex).
  - `Erratum`, a frozen dataclass of `label`, `wrote`, `means`, `why` and `where: Mapping[str, str] = {}`.
  - `Plan`, the compiled settings.
  - `run(plan: Plan, text: Text, hooks: type[Layout]) -> pl.DataFrame`, which runs spec steps 1–7 in order.
- Produces, in `flatread/layout.py`, `class Layout`:
  - Class attributes are the shared settings from the spec, with their defaults: `row`, `labels`, `variants`, `missing = frozenset({""})`, `missing_by_field`, `strip`, `dates`, `nonfinite`, `long`, `headings`, `where`, `errata`, `refusals`, `min_rows = 1`, `key`, and `member: str | re.Pattern | Callable[[str], bool] | None`.
  - `__init_subclass__` compiles `cls._plan` when `row` is set. It raises `TypeError` for:
    - an attribute not in the class's settings;
    - a label naming no field;
    - a field that no label, `carry`, `long.name` or `long.value` fills;
    - a repeated label given as a mapping;
    - a regex polars can't compile (checked with `pl.Series([""]).str.contains(p)`).
  - Classmethods: `frame(body: bytes) -> pl.DataFrame`, `rows(body: bytes) -> list[Row]` (`list(map(row, *frame.iter_columns()))` with `.to_list()`), `from_text(frame: pl.DataFrame) -> pl.DataFrame` (a text frame under labels, with locate `"row {i}"`), `read_text(body: bytes) -> Text` (implemented by the format bases), and the hooks `cells(text) -> pl.DataFrame` and `check(frame) -> None`, which are identity and no-op by default and are called only when overridden.
  - `frame` applies refusals, then `member`, then the empty-body rule, then `read_text`, then `run`.
  - Refusals: the key `b""` matches a body that is empty or only whitespace. Any other key matches when found in the first 64 KiB.

### Task 4: Delimited text (`delimited.py`)

**Interfaces:**

- [ ] **Step 3: Implement.**
  - **Decode:** decode to check UTF-8 and drop a BOM, but keep the bytes for polars.
  - **`_fast(body: bytes) -> bool`** is true only when all of these hold:
    - there is no `\x01`;
    - there is no `"`, or every line's quote count is even;

    - remove blank lines;
    - give a last line without its ending its sentinel;
    - append `separator + "\x01"` before every line ending;

    - `locate(i)` maps a row index back to its line by splitting the body only when an error is being built.

### Task 10: The scaffold (`scaffold.py`, `__main__.py`)

**Interfaces:**
- `scaffold(body: bytes, *, format: Literal["csv", "pipe", "tsv", "sheet", "json"], name: str, sheet: str | None = None, records: str | None = None) -> str` returns Python source text: a row struct plus a layout class.
